# Online Paithani by Sandip

यह एक मोबाइल-फ्रेंडली स्टैटिक वेबसाइट है।

## फाइलें
- index.html — वेबसाइट का मुख्य पेज
- style.css — डिजाइन और responsive layout
- script.js — मोबाइल मेनू और WhatsApp ऑर्डर बटन

## अपनी साड़ी की फोटो कैसे लगाएँ
अभी वेबसाइट में डेमो इमोजी प्लेसहोल्डर हैं। अपनी फोटो लगाने के लिए:
1. अपनी फोटो उसी फोल्डर में रखें, जैसे `tishu-muniya.jpg`
2. `index.html` में संबंधित `<div class="product-img">🥻</div>` को बदलकर:
   `<img class="product-photo" src="tishu-muniya.jpg" alt="Tishu Muniya">`
3. CSS में `.product-photo{width:100%;height:100%;object-fit:cover}` जोड़ें।
